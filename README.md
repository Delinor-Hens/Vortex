# 🌌 Vortex AI Engine

[![Language: C++](https://img.shields.io/badge/Language-C%2B%2B-00599C.svg)](https://isocpp.org)
[![Language: Python](https://img.shields.io/badge/Language-Python-3776AB.svg)](https://python.org)

**Vortex** — мощное десктопное приложение, объединяющее локальный ИИ и облачные провайдеры. Молниеносный бэкенд на C++ и элегантный интерфейс на Python обеспечивают комфортную работу.

Локальная модель (Vortex) работает полностью офлайн и конфиденциально, а при желании можно подключить OpenAI, Anthropic, Google Gemini, Mistral, DeepSeek, OpenRouter, Groq, Together и другие API.

---

## 🔥 Ключевые возможности

### 🧠 Искусственный интеллект
- **Локальный режим** — модель `qwen3.5:4b`, названная **Vortex**, работает офлайн.
- **Облачные провайдеры** — подключайте API-ключи популярных сервисов.
- **Три режима генерации**:
  - `Instant` — сверхбыстрые ответы.
  - `Normal` — сбалансированный (по умолчанию).
  - `Thinking` — глубокие и подробные (без ограничения длины ответа).

### 💻 Вкладка «Код»
- Генерация кода по описанию.
- Объяснение существующего кода.
- Поиск и исправление ошибок.
- Оптимизация алгоритмов.
- **Запуск кода прямо в Vortex** (Python, JavaScript, C++, C#, Java, Go, Rust и др.) — запуск выполняется вручную кнопкой «▶ Запустить» или «▶ Запустить код из поля».
- Кнопка **«🛠 Исправить»** для ручного исправления ошибок (если программа завершилась с ошибкой, кнопка активируется).
- Поддержка популярных языков.

### 📎 Работа с файлами и изображениями
- Прикрепление изображений (PNG, JPG, GIF, BMP).
- Прикрепление текстовых файлов (TXT, MD, PY, CPP, JS и др.).
- Отправка изображений в локальную модель (Ollama) для анализа.
- Вставка изображений в чат с превью.

### 🧩 Плагины (среды выполнения)
- Вкладка «Плагины» показывает установленные языковые среды.
- Автоматическое обнаружение Python, Node.js, Java, C++, C#, Go, Rust.
- Если среда не найдена — возможность установить её через winget.
- Запуск кода использует найденные среды.

### 🎮 Мини-игры
- Если модель отвечает дольше 15 секунд, запускается случайная мини-игра (Змейка, 2048, Крестики-нолики).
- Игра появляется в отдельном окне с сообщением «Модель готовит ответ. Вы можете пока сыграть в мини-игру».

### 🎨 Темы оформления
- Тёмная (по умолчанию), Светлая, OLED, Синяя.
- Выбор темы в настройках → «Темы оформления».

### ⚡ Потоковая передача
- Ответ отображается по мере генерации, без длительного ожидания.
- Исправлена потоковая передача: чанки выводятся слитно, без лишних переносов строк; обрабатываются юникод-escape-последовательности (например, `\u003e`).

### 🔒 Безопасность
- API-ключи шифруются через DPAPI.
- История чатов хранится локально.

## 🚀 Инструкция по установке
# Предисловие
Для удобства рекомендуется отключить антивирус на время установки, но это необязательно

#Инструкция по установке
1. Скачайте **`Setup.exe`** из вкладки Realises справа. Запустите его.
2. Если при запуске вылазит сообщение от антивируса - это нормально. Нажмите *Подробнее -> Выполнить в любом случае.*
3. **При скачивании в браузере:** Если загрузка приостановлена, нажмите на три точки рядом с файлом > выберите **Сохранить** > **Показать больше** > **Все равно сохранить**.
4. Далее начнется установка. Внимательно посмотрите на панель с запущенными приложениями. Если появилась иконка с **сине-желтым щитом** - нажмите её и подтвердите.
5. Далее через рабочий стол либо через поисковик windows запустите **`Vortex`**

**Подключение облачных провайдеров:**
1. **Настройки → Провайдеры**.
2. Выберите провайдера, введите API-ключ, модель.
3. Нажмите **Сохранить** и **Сделать активным**.

**Установка сред выполнения:**
1. Перейдите на вкладку **«Плагины»**.
2. Нажмите **«Проверить все»**.
3. Если нужной среды нет — нажмите **«Установить»** рядом с ней.

## 🛠️ Структура репозитория

- `/core` — C++ бэкенд: логика, HTTP-клиенты, провайдеры, токенизатор.
- `/gui` — Python GUI: главное окно, вкладки, мини-игры, темы, плагины.
- `/assets` — мультимедиа.
- `/models` — конфигурации моделей.
- `/build` — скомпилированная `vortex_core.dll`.
- `/dist` — автономный `vortex.exe`.
- `/vortex_setup.cpp` — исходник установщика.
