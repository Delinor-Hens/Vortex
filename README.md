# 🌌 Vortex AI Engine

[![License: GPL-3.0](https://shields.io)](https://opensource.org)
[![Language: C++](https://shields.io)](https://isocpp.org)
[![Language: Python](https://shields.io)](https://python.org)

**Vortex** — это высокопроизводительное десктопное приложение, объединяющее мощь искусственного интеллекта и молниеносную скорость бэкенда на C++ с элегантным, отзывчивым графическим интерфейсом на Python. 

Сердцем проекта является кастомный движок инференса нейросетей, написанный на чистом C++ для максимальной утилизации ресурсов вашего процессора, а прослойка на `ctypes` обеспечивает бесшовную интеграцию с красивым UI. Никаких облаков, никаких подписок — ваш личный ИИ-ассистент работает полностью локально и конфиденциально!

---

## 🔥 Ключевые фичи
* **⚡ Мозг на C++ (`vortex_core.dll`):** Собственный легковесный LLM-движок, оптимизированный под CPU, со встроенным токенизатором и умным менеджментом контекста сессии.
* **🎨 Современный Python GUI:** Интуитивно понятный чат-интерфейс, гибкая кастомизация тем и настроек генерации «на лету».
* **🔒 100% Локально и безопасно:** История ваших переписок сохраняется только на вашем устройстве в текстовом формате. Данные не утекут в сеть.
* **🎵 Атмосферный опыт:** Встроенное музыкальное сопровождение для глубокого погружения в работу или кодинг.

## 🚀 Быстрый старт (Инструкция по установке)

Мы позаботились о том, чтобы вам не пришлось часами настраивать окружение. Установка занимает всего 3 клика:

1. Перейдите во вкладку **Releases** на панели справа.
2. Скачайте архив **`Vortex Setup.zip`**.
3. Распакуйте архив в удобное место и запустите **`vortex_setup.exe`**. 

*И это всё! Vortex сам развернет необходимые компоненты, и вы готовы к работе.*

## 🛠️ Структура репозитория (Для разработчиков)

Если вы хотите модифицировать проект или собрать его из исходников:
* `/core` — С++ бэкенд, логика нейросети, токенизатор и управление памятью.
* `/gui` — Исходный код интерфейса на Python.
* `/assets` — Мультимедиа-ресурсы и аудиоэффекты.
* `/models` — Конфигурационные файлы LLM.
