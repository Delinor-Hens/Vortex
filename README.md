# 🌌 Vortex AI Engine

[![License: GPL-3.0](https://img.shields.io/badge/License-GPL--3.0-blue.svg)](https://opensource.org/licenses/GPL-3.0)
[![Language: C++](https://img.shields.io/badge/Language-C%2B%2B-00599C.svg)](https://isocpp.org)
[![Language: Python](https://img.shields.io/badge/Language-Python-3776AB.svg)](https://python.org)

**Vortex** — это современное десктопное приложение, объединяющее мощь локального ИИ и облачных провайдеров с молниеносным бэкендом на C++ и элегантным графическим интерфейсом на Python.

Сердцем проекта является кастомный движок инференса нейросетей, написанный на чистом C++ для максимальной утилизации ресурсов вашего процессора, а прослойка на `ctypes` обеспечивает бесшовную интеграцию с красивым UI. Vortex поддерживает **локальную модель через Ollama**, а также подключение к **OpenAI, Anthropic, Google Gemini, Mistral, DeepSeek, OpenRouter, Groq, Together** и другим API — всё в одном интерфейсе.

---

## 🔥 Ключевые возможности

### 🧠 Искусственный интеллект
- **Локальный режим** — модель `qwen3.5:4b` (называемая **Vortex**) работает полностью офлайн, конфиденциально и без ограничений.
- **Облачные провайдеры** — подключайте API-ключи популярных сервисов для доступа к передовым моделям (GPT-4, Claude, Gemini и др.).
- **Три режима генерации**:
  - `Instant` — сверхбыстрые короткие ответы.
  - `Normal` — сбалансированный режим (по умолчанию).
  - `Thinking` — глубокие, развёрнутые ответы с повышенной точностью.

### 💻 Вкладка «Код»
- **Генерация кода** по описанию задачи.
- **Объяснение** существующего кода.
- **Поиск и исправление ошибок**.
- **Оптимизация** алгоритмов.
- Поддержка популярных языков: Python, JavaScript, C++, C#, Java, Go, Rust и многих других.

### 🎮 Мини-игры
- Если модель отвечает дольше 15 секунд, автоматически запускается случайная мини-игра (Змейка, 2048, Крестики-нолики).
- Игра появляется в отдельном окне с надписью «Модель готовит ответ. Вы можете пока сыграть в мини-игру».
- После получения ответа игра автоматически закрывается.

### 🎨 Графика и UX
- **Анимация печати** — ответы посимвольно печатаются, создавая эффект живого общения.
- **Экран загрузки** с фиолетовой буквой V и анимацией при первом прогреве модели.
- **Тёмная тема** с акцентами, плавные переходы между вкладками.
- Управление музыкой и громкостью из настроек.

### 🔒 Безопасность
- Все данные (история чатов, настройки) хранятся локально в текстовом виде.
- API-ключи облачных провайдеров сохраняются в зашифрованном виде (через DPAPI).
- Полная изоляция локальной модели — ничего не уходит в интернет.

## 🚀 Быстрый старт (Инструкция по установке)

1. Перейдите во вкладку **Releases** на панели справа.
2. Скачайте архив **`Vortex Setup.zip`**.
3. Распакуйте архив в удобное место и запустите **`vortex_setup.exe`**.  
   *Установщик автоматически установит Ollama (если требуется) и загрузит локальную модель `qwen3.5:4b`.*
4. После установки можно сразу начать общение — локальная модель уже настроена.

**Подключение облачных провайдеров:**

1. Откройте **Настройки → Провайдеры**.
2. Выберите нужного провайдера из списка.
3. Введите API‑ключ, при необходимости измените модель и Base URL.
4. Нажмите **Сохранить провайдера** и **Сделать активным**.
5. Теперь все сообщения будут отправляться через выбранного провайдера.

## 🛠️ Структура репозитория (Для разработчиков)

- `/core` — C++ бэкенд: логика нейросети, HTTP-клиенты, менеджер провайдеров, токенизатор.
- `/gui` — Исходный код интерфейса на Python: главное окно, вкладки, мини-игры, настройки.
- `/assets` — Мультимедиа-ресурсы и аудиоэффекты.
- `/models` — Конфигурационные файлы моделей.
- `/build` — Скомпилированная `vortex_core.dll`.
- `/dist` — Готовый автономный `vortex.exe` (после PyInstaller).
